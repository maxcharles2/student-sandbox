# PRD - Sprint 1

## Problem
Users need assistance evaluating the importance and legitimacy of their documents.

## User
Non-native English speakers, people who cannot read and write, and people who have a difficult time with comprehension.

## Functional Requirements
**User story:**

“I want a simple explanation of what this document says.”

**Suggestions Includes:**

- Text passed to LLM
- Prompt design
- Guardrails
- Basic hallucination mitigation
- UI display of summary
- API integration
- Testing

## Acceptance Criteria
The app provides a summary explaining the inputted document in English

## Non-goals
The current feature shouldn't implement multi-language translation
